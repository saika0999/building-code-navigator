# 产品说明

## 名称

暂定名：建筑规范查阅页。

## 第一版范围

- 地区：深圳市、中山市。
- 项目：工业建筑，包括厂房、仓库、研发厂房、工业上楼。
- 阶段：项目开始前、方案设计中。

## 目标用户

- 建筑师。
- 方案负责人。
- 设计管理人员。
- 需要快速判断项目规范风险的甲方工程/设计人员。

## 关键能力

1. 梳理项目条件，暴露未知事项。
2. 根据地区和建筑类型推荐适用规范、政策、导则。
3. 生成方案阶段风险清单。
4. 支持带来源的规范问答原型。
5. 为后续本地下载、全文索引、RAG 问答预留数据结构。

## 非目标

- 第一版不做自动审图结论。
- 第一版不内置规范全文。
- 第一版不替代注册建筑师、审图机构或主管部门判断。
